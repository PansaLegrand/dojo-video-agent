## Scope

Three self-contained packs teach branded endings, chart storytelling and festival
motion. They contain method and art-direction guidance, not fixed compositions.
The existing read_skill index loads bodies only on request. Pack frontmatter
supports name and description; names must match folders. No executable loading,
community installer, recursive dependency loader or new provider jobs are added.

Folder packs and flat Markdown share one bounded loader. New local runs retain an
exact private skill snapshot so file changes cannot alter their resumed guidance.
Older builds keep their original kit archive and do not acquire the new pack names.

## Acceptance cases and gates

- Short exact-URL endings append after the complete existing timeline; portrait,
  long identity and calmer follow-up cases preserve original content and edit IDs.
- Animated bar/line charts preserve supplied labels, values, units and proportional
  encoding; missing data produces a question rather than invented claims.
- Birthday and formal company-event instructions produce appropriate distinct
  treatments, evaluated from actual rendered output without prescribed layouts.
- Loader bounds, unsupported metadata, symlinks, required-tool eligibility, saved
  guidance and paid-response recovery are tested as executable behavior.
- Run npm run check, current-profile evaluation, actual browser/decoded exports,
  commercial consumer checks and worker protocol/build checks where changed.
